# Note AI (MVP, демо-режим)

Приложение читает PDF, DOCX, TXT и фото с текстом и делает простую выжимку.
**ИИ не подключён**: результат собирает обычный алгоритм (`js/processor.js`), в интерфейсе это помечено.

## Запуск
ES-модули не работают при открытии через `file://`. Запустите локальный сервер:
`python3 -m http.server 8000` и откройте `http://localhost:8000`.
Или загрузите папку на GitHub Pages / Netlify. Нужен интернет (библиотеки грузятся с CDN).

## Файлы
- `index.html` — разметка и подключение библиотек
- `css/style.css` — стили компонентов
- `js/app.js` — интерфейс и сценарии
- `js/fileParser.js` — PDF, DOCX, TXT, OCR фото
- `js/processor.js` — демо-обработка и место для будущего ИИ
- `js/history.js` — история в localStorage
- `js/utils.js` — вспомогательные функции

## Подключение ИИ позже
Замените `processText` в `js/processor.js` запросом к вашему серверу (ключи API хранить в браузере нельзя)
и верните объект формата `{ title, demo, sections: [{ heading, paragraph?, items? }] }`.
